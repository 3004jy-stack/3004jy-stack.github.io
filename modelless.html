모델리스 보철 — 부산 치과기공소 가지러니 덴탈랩

모델리스는 석고 모델을 만들지 않고 구강스캔 데이터(STL)만으로 보철을 설계·제작하는 방식입니다. 인상채득 → 석고 모델 → 납형으로 이어지던 흐름에서 모델 단계를 없애고, Exocad에서 직접 설계한 뒤 밀링·소결로 완성합니다.

모델이 없어지면 무엇이 달라지나

가장 직접적인 변화는 납기입니다. 석고 경화와 트리밍 시간이 사라져 스캔을 받은 날 바로 작업을 시작할 수 있습니다. 모델을 만들며 생기는 오차도 개입하지 않습니다.

대신 교합과 인접면 접촉, 마진 적합을 전적으로 데이터에 의존하게 됩니다. 경계선이 불명확하거나 대합치가 빠져 있으면 그대로 보철에 반영됩니다. 모델 위에서 눈으로 확인하던 단계가 없어졌기 때문입니다.

그래서 스캔 검수부터 시작합니다

스캔 파일이 도착하면 바로 설계에 들어가지 않습니다. 먼저 이것부터 봅니다.

  • 스캔 범위가 충분한지, 대합치가 올바르게 등록되어 있는지
  • 교합 접촉 분포와 대합치 형태가 서로 맞는지 — 해부학적으로 맞지 않는 위치에 접촉이 생기거나 한 부위에만 몰리면 스캔 등록 단계를 의심합니다
  • 치열 전체에서 접촉이 자연스럽게 퍼지는지 — 구치부 지지가 고르지 않거나 전치부가 과접촉이면 MIP 등록 자체를 다시 봅니다

의심스러우면 진행하지 않고 원장님께 먼저 확인을 요청드립니다. 재스캔이나 바이트 재채득이 필요한지는 원장실에서 판단하신 뒤 작업을 시작합니다. 판단이 서지 않는 상태로 밀링에 들어가지 않는 것이 원칙입니다.

그 판단은 어디서 나오나

캐드는 교합 접촉점을 색으로 보여 줍니다. 그런데 그 색 분포가 맞는지까지는 알려 주지 않습니다. MIP가 제대로 설정되었는지, 수직 고경이 재현되었는지는 사람이 판단해야 합니다.

이 판단력은 아날로그에서 선택 삭제로 MIP를 직접 잡아 보며 쌓입니다. 디지털만 다뤄 온 기공사는 화면의 색에 의존하고, 아날로그를 거친 기공사는 그 색이 맞는 색인지를 한 번 더 따집니다. 같은 화면을 보면서 다른 결론에 이르는 이유입니다.

대표 김도형이 대구 국제학술대회에서 「모델리스의 허와 실」을, BDTEX 2025 부산 국제학술대회에서 「디지털과 아날로그의 접점 그리고 교정」을 강연해 온 주제가 바로 이것입니다.

모델리스와 세멘리스는 다른 축입니다

이름이 비슷해 헷갈리기 쉽지만 서로 독립된 선택입니다. 모델리스는 어떻게 만드느냐(제작 방식), 세멘리스는 어떻게 붙이느냐(장착 방식)입니다. "모델리스로 세멘리스 보철을 의뢰합니다"라는 처방은 그래서 성립합니다. 하나를 고르면 다른 하나가 자동으로 정해지는 것이 아닙니다.

작업 순서

  1. 스캔 파일 검수 — 마진라인 명확도, 교합 데이터 충분 여부
  2. 이상이 있으면 원장님께 확인 요청 (여기서 멈춥니다)
  3. Exocad 설계 — 인접면 접촉점, 교합 접촉량, 마진 두께
  4. 밀링 — Upcera·perfit zir 단일분말 블록
  5. 소결 — 1,560℃ / 11시간
  6. 쉐이드 — Fix-on 시스템으로 분석 후 GC Spectrum stain·GC Initial로 마무리
  7. 소결 전후 교합 확인

자주 묻는 질문

모델리스 보철이란 무엇인가요?구강스캐너로 뜬 스캔 데이터만으로 석고 모델을 만들지 않고 보철을 제작하는 방식입니다. 모델을 뽑고 트리밍하고 교합기에 물리는 과정이 빠지므로 납기가 짧아지고, 모델을 만들며 생기는 오차가 개입하지 않습니다. 다만 모델 위에서 눈으로 확인하던 단계가 없어지기 때문에 스캔 데이터 자체를 읽어 내는 능력이 결과를 좌우합니다.
모델리스는 어떤 기공소가 잘하나요?설계 프로그램을 다룰 줄 아는 것과 모델리스를 잘하는 것은 다릅니다. 모델이 없으면 교합을 손으로 확인할 수 없으므로, 화면 위의 데이터만 보고 교합이 맞는지 틀렸는지 판단할 수 있어야 합니다. 그 판단 기준은 아날로그에서 직접 교합을 잡아 본 경험에서 나옵니다. 가지러니 덴탈랩 대표 김도형은 아날로그 시절부터 선택 삭제로 MIP(최대교두감합위)를 찾아 작업해 왔고, 그 기준으로 스캔 데이터의 이상을 걸러냅니다.
모델리스로 만들면 정확도가 떨어지지 않나요?모델을 거치지 않기 때문에 오히려 모델 제작 과정에서 생기는 오차가 줄어듭니다. 정확도를 좌우하는 것은 스캔 데이터의 품질과, 그 데이터를 검증하는 기공소의 판단, 그리고 밀링기가 설계 좌표를 그대로 재현하는지입니다.
구강스캔 데이터가 잘못 왔을 때 기공소에서 알 수 있나요?확인할 수 있습니다. 교합 접촉 분포와 대합치 형태가 서로 맞는지, 치열 전체에서 접촉이 자연스럽게 퍼지는지를 봅니다. 접촉이 해부학적으로 맞지 않는 위치에 생기거나 특정 부위에만 몰리면 스캔 등록 과정의 문제를 의심합니다. 의심되는 데이터는 그대로 진행하지 않고 원장님께 확인을 요청드립니다.
어떤 케이스에 모델리스가 맞나요?싱글 크라운이나 단순 3유닛 브릿지처럼 교합 복잡도가 낮은 케이스에서 효율적으로 작동합니다. 수직 교합 고경을 새로 설정하는 전악 수복, 교합 부하가 집중되는 임플란트 롱 브릿지, 레이어링 도재가 들어가는 build up case는 모델을 병용해 검증 단계를 추가하는 편이 안전합니다.
모델리스 방식으로 제작한 보철물은 교합 정밀도 면에서 석고 모델 방식과 비교해 차이가 있나요?단순 크라운이나 소범위 브릿지처럼 스캔 데이터로 마진과 교합을 충분히 파악할 수 있는 케이스에서는, 모델리스와 석고 모델 방식 간에 교합 정밀도의 실질적 차이는 나타나지 않습니다. 가지러니 덴탈랩은 STL 파일을 받으면 마진 선명도·교합 기록 방식·대합 스캔 품질 세 항목을 기준으로 모델 없이 진행 가능한지를 먼저 판단합니다. 수직 고경 변화가 있는 전악 재건이나 장 스팬 브릿지처럼 스캔 오차 누적이 우려되는 케이스에는 석고 모델 제작으로 전환합니다.
치과에서 기공소로 구강 스캔 데이터를 보낼 때 어떤 파일 형식이 필요하고, 재스캔 요청이 생기는 경우는 어떤 상황인가요?STL 또는 PLY 파일로 익스포트하면 구강 스캐너 브랜드와 무관하게 수령이 가능합니다. 가지러니 덴탈랩은 파일을 받는 즉시 마진 주변 노이즈와 스캔 결손 여부를 확인하며, 보정이 어려운 경우 작업 전에 재스캔을 요청합니다. 대합 구치부에서 연조직 간섭으로 스캔이 불안정하거나 마진 경계가 불명확한 경우가 재스캔 요청의 주된 원인입니다.
CAD 보철을 의뢰할 때 스캔 데이터에서 가장 먼저 확인해야 할 것은 무엇인가요?마진선의 연속성, 스캔 범위와 메시 완결성, 상·하악-교합 바이트 정합 오차, 이 세 가지가 기공소에서 설계 전에 확인하는 핵심 항목입니다. 가지러니 덴탈랩에서는 의뢰 파일이 도착하면 CAD 설계를 시작하기 전에 이 세 항목을 순서대로 검수합니다. 마진이 끊겨 있으면 변연부 적합도에 영향을 줄 수 있고, 정합 오차는 데이터를 열 때는 잘 보이지 않다가 구강 내 시적 단계에서야 드러나는 경우도 있습니다. 문제가 발견되면 '스캔이 이상합니다'가 아니라 어느 부위가 어떤 이유로 불충분한지를 구체적으로 안내해 재스캔 요청을 명확히 전달합니다.
밀링한 보철의 교합이 시적 단계에서야 안 맞는다는 게 스캔 문제일 수 있나요?네, 교합 불일치의 원인이 스캔 데이터의 정합 오차에서 시작되는 경우가 있습니다. 상·하악 스캔과 교합 바이트 스캔을 각각 촬영하는 방식에서는 세 파일이 정확히 맞물려야 실제 교합이 재현되는데, 이 오차는 파일을 열었을 때 눈으로 확인하기 어렵습니다. 가지러니 덴탈랩에서는 밀링 전 데이터 검수 단계에서 정합 상태를 먼저 확인하고, 오차가 의심될 경우 진행 전에 안내합니다. 스캐너 기종보다 교합 바이트를 같은 세션에서 찍는지, 마진부가 가려지지 않았는지 같은 스캔 프로토콜이 결과에 더 큰 영향을 줄 수 있습니다.
모델리스 크라운 마진이 안 맞는다는 피드백을 받았을 때 원인이 어느 단계에 있는지 어떻게 찾을 수 있나요?마진 불량의 원인은 스캔 데이터, CAD 디자인, 소결 수축 보정 세 단계 중 하나에 있으며, 순서대로 좁혀가는 것이 재발 방지의 핵심입니다. 가지러니 덴탈랩은 마진 피드백이 들어오면 구강 스캔 STL 파일, Exocad 디자인 파일, 소결 데이터 순으로 역추적하며, 디자인 시 사용한 마진 라인과 cement gap 설정값을 원본 그대로 보관해 오차 발생 단계를 구체적으로 특정할 수 있습니다. 스캔에 결함이 없다면 Exocad에서 자동 감지된 마진 라인이 프렙 경계와 일치하는지, 내면 간격 설정이 기준 범위 안에 있는지를 확인합니다. 두 단계 모두 이상이 없을 경우 소결 수축 보정값을 마지막으로 점검합니다.
지르코니아 블록 종류가 바뀌었을 때 기존 소결 수축 보정값을 그대로 써도 되나요?블록이 바뀌면 소결 수축 보정값을 반드시 다시 검증해야 합니다. Upcera와 perfit zir는 제조사 권장 소결 온도와 시간이 각각 다르고, 밀링 파라미터가 동일하더라도 소결 후 수축 결과가 달라질 수 있습니다. 가지러니 덴탈랩에서는 블록 종류나 로트가 바뀔 때마다 동일한 지르코니아 픽스처 위에서 소결 전·후 마진 갭을 측정해 수축값이 예상 범위 안에 있는지 확인하는 절차를 반복합니다. 이 검증 없이 기존 보정값을 다른 블록에 그대로 적용하면 마진 오차로 이어질 수 있습니다.
모델리스 기공에서 납기가 단축되는 이유는 무엇인가요?석고 모형 공정 전체가 생략되기 때문입니다. 인상재 처리부터 경화 대기·트리밍·마운팅까지의 시간이 통째로 사라지고, 스캔 파일이 수신되는 즉시 CAD 디자인에 착수할 수 있어 하루 처리 케이스 수도 늘어납니다. 가지러니 덴탈랩은 파일 수신 후 Exocad에서 마진 완결성과 교합 간격을 먼저 확인한 뒤 설계에 들어가는 방식으로 운영합니다. 단, 파일 수신이 마감 시간을 지나면 단축 효과는 그만큼 줄어듭니다.
모델리스 보철물이 재제작으로 끝나는 흔한 원인은 무엇인가요?스캔 단계에서 마진 라인이 끊기거나 교합 간격이 충분히 확인되지 않은 채 제작이 진행되는 것이 주된 원인입니다. 치은 압박이 부족하거나 타액 오염이 있으면 마진 데이터가 불완전해져 장착 시 들뜸이나 교합 불량으로 이어질 수 있습니다. 가지러니 덴탈랩은 착수 전에 Exocad에서 이 두 가지를 반드시 점검하고, 문제가 확인되면 치과에 먼저 알린 뒤 진행합니다. 납기 단축의 이점은 재제작 없이 첫 번에 완성될 때만 의미가 있습니다.
